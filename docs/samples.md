> 이 문서의 회사명, 담당자명, 이메일, 연락처, 선명·항차, 참조번호, 화물 정보, 운임·비용 금액은 모두 가명 또는 임의로 바꾼 값이다.

## 6. 용어 정리

| POL / POD | 선적항(Port of Loading) / 양하항(Port of Discharge) |

| 20'GP / 40'HC(40HQ) | 20피트 일반 컨테이너 / 40피트 하이큐브(높이가 높은) 컨테이너 |

| EXW | 공장 인도 조건. 수입자가 출발지 픽업부터 비용과 위험을 부담 |
| O/F | Ocean Freight, 해상운임 |

| 부보 | 보험 가입 |
| 스페이스(선복) | 선박에 화물을 실을 수 있는 공간 |

또한 견적에 포함되지 않고 실제 선적 진행 시 추가로 발생할 수 있는 비용이 있다면 해당 항목도 함께 안내 부탁드립니다.
추가로 견적 산출을 위해 필요한 정보나 확인사항이 있다면 말씀 부탁드립니다.
